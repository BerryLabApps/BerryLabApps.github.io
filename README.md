# BerryLabApps.github.io

The BerryLab site on GitHub Pages: https://berrylabapps.github.io/

- `index.html` — the games page, English and Russian in one file; `assets/site.js` picks the language (`?lang=`, then the saved choice, then the browser language).
- `assets/site.css` — styles for the games page and the privacy pages.
- `assets/favicon.svg` and `assets/apple-touch-icon.png` — the studio icon; the 180 px PNG sits on the cream background because iOS fills transparency with black.
- `assets/img/<app>-icon.webp` — each game's Google Play icon, 192 px, square; the page rounds the corners.
- `assets/img/<app>-banner*.webp` — each game's Google Play feature graphic, 1024×500, shown whole; the Hat Game one has a version per language.
- `assets/img/stores/` — the Google Play and Apple logos on the store buttons, traced from the official badges.
- `<app>/privacy/index.html` — privacy policies of Alias, Hat Game, Quiz Battle and Alias Premium (iOS, collects no data), generated by `python _tools/build_privacy.py`. Edit the script, not the pages.
- `app-ads.txt` — authorized sellers for the ad networks; `_config.yml` keeps Jekyll publishing it.

Support and privacy questions go to one address, berrylab.app@gmail.com.
